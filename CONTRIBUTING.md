# Contributing

Thanks for wanting to help! This is a small project, so keep it simple.

## Ways to contribute
- Report bugs (include device, OS version, reproduce-able instruction)
- Suggest features by opening an issue first
- Pick up an issue labeled `good first issue`

## Before opening a PR
- Keep PRs small and focused on one change
- For big changes, open an issue to discuss first

## AI-assisted code
AI-generated code is welcome, but you are responsible for it. Test it
on real footage and make sure you understand what it does.
